# 3D Retro CRT Portfolio — Sofian Sarrag

An interactive, animated 3D retro computer portfolio set inside a sunlit room, built with HTML, CSS, JavaScript, and Three.js. Visitors explore a warm amber-gold CRT monitor interface to learn about my background in software engineering, cloud computing, and model-driven development.

## Features

- **3D Room & CRT Monitor:** Camera focus zoom on load, cream plaster wall, wooden window with sunlight and greenery, bookshelf, desk props, and a synchronized CRT screen overlay.
- **Interactive Desktop & Windows:**
  - **About Me:** BSc Software Engineering student at Epoka University and Applied Science Lab experience at Hochschule Fulda (cloud computing, NIST model, CI/CD, IaC, Lua, and Umple).
  - **Work:** Currently marked as *Under Construction* as additional project builds are added.
  - **Contact:** Opens a contact flow targeting `admin@sofiansarrag.tech`.
  - **CV:** Opens the resume PDF in a new tab.
- **Desk Easter Eggs:** Interactive details including a swimming trophy, a Libyan flag, purple ceramic vases with plants, and a blue notebook with a red pen.
- **Live Visitor Clock:** Displays the visitor's real-time clock on the CRT taskbar.
